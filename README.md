# 🏠 Модель оценки стоимости квартир с использованием эмбеддингов и ансамблей (В доработке)

Проект направлен на прогнозирование стоимости квартир на основе числовых характеристик и текстового описания. В основе лежат ансамблевые модели и текстовые эмбеддинги, полученные из описаний недвижимости с использованием современных NLP-моделей.

Собран и использован датасет из более 45 тыс предложений из открытых источников. 
## 📌 Обзор проекта

Цель — разработка гибкой и точной модели, способной учитывать как структурированные признаки (площадь, этаж, тип здания и т.д.), так и неструктурированные текстовые данные (описание квартиры). Это позволяет учесть дополнительные факторы, влияющие на цену, такие как отделка, ремонт, вид из окна и т.д.

## 🧠 Ключевые особенности
- Использование **ансамблевых моделей**: XGBoost, LightGBM, Random Forest
- Векторизация текстов с помощью **трансформеров (BERT/DistilBERT)** и классических методов (TF-IDF)
- Объединение эмбеддингов и числовых признаков в единую матрицу признаков
- Визуализация важности признаков и ошибок модели

## 🔍 Используемые признаки
- **Общая площадь (м²)**
- **Количество комнат**
- **Этаж / Общее количество этажей**
- **Год постройки**
- **Город / Район**
- **Тип здания**
- **Координаты (широта/долгота)**
- **Текстовое описание квартиры**

## 🛠️ Стек технологий
- Python, scikit-learn, pandas, numpy
- XGBoost, LightGBM, CatBoost
- Huggingface Transformers, Sentence-BERT
- Matplotlib, Seaborn
- Jupyter Notebooks

## 📈 Этапы пайплайна

1. **Сбор и очистка данных**
2. **Обработка текста**: очистка, токенизация, извлечение эмбеддингов
3. **Объединение признаков**
4. **Обучение ансамблевых моделей**
5. **Оценка по метрикам MAE, RMSE, R²**
6. **Предсказание цен для новых квартир**
